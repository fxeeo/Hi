About the Assam Flood PDP

This is a prototype multi-page full-stack web application designed for Assam flood management and public awareness.

Architecture

  • Frontend: HTML5, CSS3, Vanilla JS
  • Backend: Python, Flask
  • Templating: Jinja2

For a real deployment, this system would be backed by a PostgreSQL database and connected to live government APIs.
